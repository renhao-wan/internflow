# 主题笔记整理

单文件执行手册。**只移动，不改内容；只整理 `主题笔记/`，不动日志、素材库、架构图和实习总结。**

## 第一步：解析参数

| 参数 | 行为 |
|---|---|
| 无 | 按配置的模式整理根目录平铺文件和 `未分组/` |
| `module` / `type` / 自定义文本 | 本次按该模式重排全部子目录，成功后问是否写回配置 |
| `--mode` | 只重新选择分组模式并写回配置，不移动文件 |
| 其他 | 提示可用参数，不做任何移动 |

## 第二步：定位

按插件根目录的 `references/workspace.md`（`${CLAUDE_PLUGIN_ROOT}/references/workspace.md`）读项目根目录的 `.claude/internflow.local.md`，取 `rules` 和 `log_root`；用户本次给的路径优先。

定位本次实习目录：只有一个时直接用；多个时问整理哪一段，不跨实习整理。

目标目录：`<实习目录>/主题笔记/`。不存在时说明没有主题笔记，结束。

## 第三步：确认分组模式

- 配置里有 `topic_grouping` → 直接使用
- 没有 → 询问一次：

```text
主题笔记按什么分组？
  1. 业务模块（库存、订单、支付……）
  2. 笔记类型（问题排查、架构、业务理解……）
  3. 自定义（直接说，例如「按系统分层」）
```

用户选完后，普通整理直接使用；`--mode` 写回配置后结束。

`module` 和 `type` 是固定选项；用户选 3 时，把用户的话原样存进 `topic_grouping`，不要改写成 `module` 或 `type`。

## 第四步：扫描

- **普通整理**：根目录下的 `.md` 文件 + `未分组/` 下的文件
- **重排（带参数）**：全部子目录和根目录下的 `.md` 文件

非 `.md` 文件不动，只在报告里说明。

没有可整理的文件时，说明已经整理过，结束。

## 第五步：全目录同名检查

整理前扫描 `主题笔记/` 下所有文件（含所有子目录），按文件名分组。

出现同名时：

- 相关文件全部不动
- 列出全部路径
- 报告「存在同名文件，先决定保留哪个或改名」
- 其余不冲突的文件照常整理

这一步不受目标目录限制。Obsidian 的 `[[文件名]]` 全局按文件名解析，跨目录同名也会歧义。

## 第六步：归位

按模式判断，读文件名和正文首段，不读全文、不读日志：

- 能明确归入现有目录 → 复用
- 属于新模块或新类型 → 新建目录
- 建议目录与已有目录近义（如已有「库存」，建议「库存中心」）→ 列出让用户选，不自动合并、不直接新建
- 判断不了 → `未分组/`

`未分组/` 里的文件每次整理都重新评估：能归位的移出，仍判断不了的留在原地，报告剩余数量。

分组只做一层，不再往下嵌套。

## 第七步：执行

- 直接执行，不逐条确认
- 不改文件内容
- 不改日志里的 `[[链接]]`；Obsidian 按文件名解析，移动后仍有效
- 不覆盖任何已有文件
- 移动后删除 `主题笔记/` 下清空的子目录
- **`主题笔记/` 根目录始终保留**，不删除
- 根目录下的平铺文件移走后，根目录本身保留

有同名冲突时，只跳过冲突文件，其余照常移动。

## 第八步：写配置

- 普通整理：配置不变
- 带参数整理：全部移动成功后，问「把 `type` 写回配置吗」，用户确认才写
- `--mode`：询问后写回，不移动文件
- 整理失败或中途中断：保留原配置，报告已经完成的移动

写配置时只改 `topic_grouping` 字段，不动 `rules` 和 `log_root`。

## 第九步：报告

固定口径：

```text
整理完成
  模式：业务模块
  移动 8 个文件
  分布：库存 3、订单 3、未分组 2
  未处理 1 个：网关配置差异.md（同名文件）
  删除子目录 1 个
  未分组剩余 2 个
```

有未处理项时说明原因，不猜。

## 重排前的影响确认

带参数重排或改模式前，先展示影响范围，用户确认后才执行：

```text
当前：业务模块（库存/、订单/、未分组/）
改为：笔记类型（问题排查/、架构/、业务理解/）

涉及 12 个文件、3 个目录。
确认后按新模式重新归位，清空的旧目录删除，未分组重新评估。
```

- 用户确认后才执行
- 中途放弃：配置不变、文件不动
- 有冲突未移动的文件保留，对应目录不删
- 旧目录清空后删除

## 交付前检查

- 只动了 `主题笔记/` 下的文件
- 文件内容没有变化
- 没有覆盖已有文件
- `主题笔记/` 根目录保留
- 没有删除非空目录
- 同名冲突已报告，没有自行取舍
- `未分组/` 已重新评估，剩余数量已报告
- 没有跨实习目录整理
- 配置只在成功后按需写回
- 不自动 `git commit`

## 禁止

- 不改日志、素材库、架构图、实习总结
- 不改文件内容或链接
- 不嵌套子目录
- 不删除 `主题笔记/` 根目录
- 不删除非空目录
- 不自动合并同名文件或近义目录
- 不把自定义模式改写成 `module` 或 `type`
- 不自动 `git commit`
